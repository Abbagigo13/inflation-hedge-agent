# Design System: Inflation Hedge Agent

## 1. Design Philosophy

The agent is invisible. The user does not need to understand smart contracts or RFQs. The UX must inspire **trust**, **calm**, and **security**. The design should reflect a "Set and Forget" wealth preservation model.

## 2. Color Palette

* **Primary (Trust):** Celo Forest Green (`#1E4D2B`)
* **Secondary (Action):** Ripo Purple (`#7C3AED`)
* **Background:** Off-white/Sand (`#FDFBF7`) for a clean, non-cluttered feel.
* **Alert (Inflation):** Soft Amber (`#F59E0B`) for warnings.
* **Success (Hedge Executed):** Bright Green (`#10B981`).

## 3. Typography

* **Headings:** Inter or SF Pro (Bold, clean).
* **Body:** Roboto Mono (for transaction hashes and technical data) or Inter (for readable descriptions).
* **Tone:** Professional, reassuring, and clear. Avoid crypto-jargon (e.g., use "Protect Savings" instead of "Execute Swap").

## 4. Key UI Components (For the Demo Video/App)

* **Dashboard:** A simple line graph showing "Your Balance in USD" vs "What it would have been in wARS".
* **Agent Activity Log:** Plain English logs (e.g., *"Oct 12: Inflation spiked. I moved 50 wARS to USDT. You saved $12."*)
* **Status Indicator:** A glowing green dot showing "Agent is actively monitoring".
